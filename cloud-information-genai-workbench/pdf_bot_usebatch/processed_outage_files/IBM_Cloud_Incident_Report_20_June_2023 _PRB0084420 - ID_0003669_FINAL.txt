**IBM Cloud**

The outage started on June 20, 2023, at 03:49 UTC and lasted for 18 hours and 26 minutes.

Here are the services impacted by the outage, listed one by one:

* VPC underlying host operating system was restored.
* All bare metal hosts were back online.
* Power was restored on the affected rack.
* Facilities grid power supply was restored and transition from generator to utility was completed.
* IBM Cloud Site Operator Engineering team were notified that power was restored after inspection.
* VPC SDN was restored.
* SQL Query - SQL jobs/queries experienced long delays and eventually failures for all submitted jobs. Streaming jobs were running as normal where the impact was limited to SQL batch jobs.
* Databases - IBM Cloud Databases had an impact due to worker nodes being in critical status.
* Load Balancer - Data plane and control plane for Load Balancers were impacted.
* Network Infrastructure - All IBM Cloud services experienced connectivity issues.
* VPC VPN - Impacted customers experienced VPN Gateway provisioning failures and VSI was stuck in "pending" status.
* Code Engine - Impacted customers experienced delays in creating or updating applications, due to the degraded performance of the system.
* Watson platform - Impacted customers experienced intermittent 5xx errors when using the following Watson AI services: 
Watson Assistant
Discovery
Natural Language Understanding
Language Translator
Knowledge Studio
