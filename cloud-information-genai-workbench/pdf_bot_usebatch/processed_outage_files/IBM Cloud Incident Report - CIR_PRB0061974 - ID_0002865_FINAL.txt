**Summary of Outages**

The incident started on June 13, 2021, at 01:30 UTC and lasted for 3 days, 1 hour, and 32 minutes. The outage affected several services across multiple regions.

**Cloud Providers Impacted**

* IBM Cloud
* Private DNS Services (not a cloud provider but impacted)

**Services Impacted**

* Data Catalog
* IKS
* is-ng-vpc
* Code Engine
* Cloudant
* MongoDB

**Outage Details per Service**

**IBM Cloud**
-----------------

* **Service**: Data Catalog
* **Region**: Sydney
* **Availability Zone**: Not specified
* **Impact Date**: June 13, 2021, at 01:30 UTC
* **Duration**: 3 days, 1 hour, and 32 minutes
* **Root Cause**: Connections to Cloudant database from private DNS Services resolvers stuck in a 'CLOSE_WAIT' state on IBM Cloud load balancers.
* **Downtime Period**: June 13, 2021, at 01:30 UTC - June 16, 2021, at 03:02 UTC
* **Resolved Date**: June 16, 2021, at 03:02 UTC
