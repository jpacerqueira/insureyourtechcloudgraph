**Summary of Outage**

IBM Cloud was impacted by a utility grid outage that started on 20 June 2023 03:49 UTC and lasted for 18 hours 26 minutes. The root cause of the outage was a failed relay on the generator control system resulting in a soft (partial) failure scenario that impeded handover between the UPS (battery) and generator systems.

The impacted services were:

* Watson platform
* VPC
* Load Balancer
* Network Infrastructure
* VSI
* SQL Query
* Databases
* Cloud Foundry
* Containers Kubernetes
* DNS
* VPC VPN
* Code Engine

The outage affected the FRA05 and EU-DE-3 regions/availability zones.

**Overall Summary**

IBM Cloud was impacted by a utility grid outage that started on 20 June 2023 03:49 UTC and lasted for 18 hours 26 minutes. The root cause of the outage was a failed relay on the generator control system resulting in a soft (partial) failure scenario that impeded handover between the UPS (battery) and generator systems. The impacted services were affected by the outage, which resulted in degraded performance and delays in creating or updating applications.
