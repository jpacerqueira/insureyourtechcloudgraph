**Outages Summary**

The following cloud providers were impacted: Microsoft Azure, Amazon AWS was not mentioned in the text but A T&T was mentioned which is a service provided by AT&T (a company that uses AWS) however it was not specified if it was an AWS service or a service of AT&T. 

Microsoft Azure and A T&T experienced outages.

**Outage Details**

**Azure SQL Database and Managed Instance**

* Outage started: 11:45 UTC on July 30, 2024
* Duration: 8 hours and 58 minutes
* Root cause: Storage availability failures in various control and data plane clusters
* Services impacted: Azure SQL DB and Azure SQL Managed Instance customers in the region
* Downtime period: All unhealthy nodes were detected within one minute of SQL unavailability, and investigation and mitigation workstreams were established

**A T&T**

* Outage started: 11:46 UTC on September 12, 2024
* Duration: 28 minutes
* Root cause: Automated systems in the Microsoft network shifted traffic away from A T&T, resulting in issues accessing services
* Services impacted: A T T customers connecting to Microsoft services
* Downtime period: Traffic was shifted away at 13:01 UTC, and the issue was resolved after A T T reverted a change at 13:14 UTC
