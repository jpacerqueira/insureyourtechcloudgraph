**Summary of Outage:**
The outage occurred on February 26, 2025, starting at 18:39 UTC and lasted for 17 hours and 16 minutes. The root cause was a key rotation issue in the Managed Identity infrastructure. The services impacted were Azure Container Apps, Azure SQL, Azure SQL Managed Instance, Azure Front Door, Azure Resource Manager, Azure Synapse Analytics, Azure Databricks, Azure Chaos Studio, Azure App Services, Azure Logic Apps, Azure Media Services, and Microsoft Power BI. The outage was resolved on March 1, 2025, at 12:55 UTC.
