**Summary of Outages**

The outages affected Amazon AWS services in the Northern Virginia (us-east-1) Region.

**Services Impacted**

* CloudWatch Logs
* Amazon Data Firehose
* Event framework that publishes Amazon S3 events
* Amazon Elastic Container Service (ECS)
* AWS Lambda
* Amazon Redshift
* AWS Glue
