**Overall Summary**

The outage impacted multiple services across Azure in China, including Cosmos DB, Azure Virtual Desktop, Azure Databricks, Azure IoT Hub, Azure Policy, Azure Kubernetes Services, Azure Service Bus, Azure Logic Apps, Azure Data Factory, and Azure AI Speech Services. The outage occurred between 03:45 CST and 06:00 CST on April 23, 2024, and lasted for approximately 2 hours and 15 minutes.

**Root Cause**

The root cause of the outage was a configuration change through a domain registrar that resulted in a service disruption.

**Recommendations**

To prevent similar outages in the future, it is recommended to:

* Implement additional validations to obtain nameserver verification by directly resolving the zone over internet
* Ensure that the right people in your organization will be notified about any future service issues - by configuring Azure Service Health alerts
