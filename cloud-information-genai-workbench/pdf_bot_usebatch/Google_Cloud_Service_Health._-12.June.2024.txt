**Root Cause:**

The root cause of the outage was a novel form of user request to the GenerateContent API triggering intermittent segmentation faults in the Vertex Serving Prediction API servers. This caused an affected server to restart after a segfault, and load balancers sent user queries to other healthy API servers until the affected server returned to service.
