Here is the summary of the outage:

**Cloud Provider:** Microsoft Azure
**Outage Details:**

* **Incident Start Date and Time:** August 27 at 02:47 UTC
* **Duration:** The outage lasted for approximately 1 day, with a brief period of recovery in the middle.
* **Affected Regions and Availability Zones:** West US 2 region, which includes multiple datacenters across three Availability Zones on two campuses.
* **Impacted Services:**
	+ Azure Virtual Machines (VMs) running Ubuntu 18.04
	+ Azure Kubernetes Service (AKS)
	+ Azure Monitor
	+ Application Insights
	+ Log Analytics
	+ Microsoft Sentinel
* **Root Cause:** A bug in Ubuntu that caused DNS resolution errors, which impacted all affected services.
* **Downtime Period:**
	+ The outage started at 02:47 UTC on August 27 and lasted for approximately 12 hours (until 14:47 UTC).
	+ During this time, customer s may have experienced pod creation errors in AKS, inability to access Azure Monitor, Application Insights, Log Analytics, and/or Microsoft Sentinel log data, and missed or delayed Log Search alerts and/or Microsoft Sentinel alerts.
* **Resolution Date and Time:** The outage was marked as resolved after the affected services were restored.
